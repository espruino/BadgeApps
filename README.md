# Espruino ePaper Badge Apps

Applications (and loader) for the Espruino ePaper Badge - https://www.espruino.com/Badge

**Check this out live at http://espruino.github.io/BadgeApps**

If your Badge still has WebAI badge firmware on it, long-press the `SHARE` button until the LEDs turn solid blue. Then you can connect using either Web Bluetooth or USB (Web Serial).

You can also use the Disk icon that appears next to the WebAI app https://espruino.github.io/BadgeApps/?id=webai when connected to your Badge in order to download any saved contact info.

**Please do submit PRs for new apps!**
